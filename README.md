# Фото КМ

Это PWA-приложение для сотрудников.

## Что делает приложение
- Сотрудник загружает фото в Яндекс Диск по категориям
- Имя файла содержит дату, время и имя сотрудника
- Есть режим просмотра файлов сотрудника:
  - за неделю
  - за месяц
  - все файлы

## Что уже работает
- Загрузка фото работает
- Список файлов по сотруднику работает
- Фильтры неделя / месяц / все работают

## В чём проблема
Часть JPEG-файлов стабильно не показывается в превью и не открывается по нажатию.
Другие JPEG-файлы из той же папки открываются нормально.

## Что уже проверено
- Права токена Яндекс Диска исправлены
- Список файлов получается
- Проблема не в имени файла и не в папке
- Проблема не в расширении .jpg
- Один и тот же набор файлов всегда ведёт себя одинаково:
  - некоторые открываются
  - некоторые не открываются
- Скриншот проблемного файла загружается и открывается нормально
- Пример:
  - рабочий файл: 2.4 МБ, 4032x3024
  - нерабочий файл: 4.15 МБ, 4032x3024
  - скриншот проблемного файла: работает

Желательно без хранения отдельных preview-копий на Диске.
